# 本项目调试约定

**用户要求全部实机测试后台静默。** 仅使用 noactivation 受保护、仍在后台且未最小化的归属实例。`mc_input` 除 `/help`、`/state` 外均禁止；使用 SDK/UI 回调和后台 WGC 截图。窗口调整始终使用 `SWP_NOACTIVATE`，不激活、不恢复最小化或最大化窗口。前后检查保护失效时直接报错，不回退抢焦点操作。

迁移来源与本地适配见根目录 `docs/MIGRATION.md`。当前项目先验证独立 shader 原型，尚未集成 Pyreact 时，Fiber 树与框架专用诊断不可用；应使用 ModSDK 状态、日志和真实画面。

- 以当前项目路径创建受管实例，保存 session 和 owner，后续调用通过 `instances.py exec` 绑定。
- 保留 PID 创建时间与游戏内 session 标记核对。不得通过进程名关闭其他会话的客户端。
- 新建独立测试世界，不写入玩家已有世界，不继承来源工程的建筑、投影或偏好数据。
- 对文字验收先设置固定进度，记录实际呈现后截图；CPU 预览或 UI 树不代替 MC 渲染证据。
- 快速修改 shader 后应核对引擎是否重新编译。遇到缓存失败时记录并创建新的本项目实例，不连续启动无归属游戏。
- 真实桌面输入使用受管锁；仅代码执行与截图时也必须保持实例绑定。
- 迁入的 `_game_bridge.py` 保留对框架扩展诊断的适配。游戏内没有对应能力时应报告不可用，不假定已迁入旧项目的业务组件。
- 日志、截图、进程回执、临时资源放 `.runtime/`；session token 不提交。
