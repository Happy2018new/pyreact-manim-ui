# Agent 协作职责

原工程只有技能与 MCP 配置，没有可直接迁移的根 `AGENTS.md` 或自定义 agent 定义。本文件与根 `AGENTS.md` 是按新项目目标建立的协作约定，不是运行中的 agent 状态存档。

| 职责 | 负责范围 | 交付 |
| --- | --- | --- |
| 集成与渲染 | MC 生命周期、shader、资源与播放控制 | 可启动、可暂停定位的实机原型 |
| 场景编译 | 固定 Manim 参考、轮廓/动画导出、版本化数据 | 可重建的输入与输出、误差说明 |
| 验证与文档 | 独立参考检查、截图比对、技能与计划维护 | 有证据的结论与未关闭项 |

角色是任务拆分方式，不固定模型、数量或特权。具体文件所有权在每轮任务开始时声明。使用受管 MC 实例时每个代理必须独立 owner/session；默认先使用一个本项目实例，确需并行才增加，始终遵守用户当前的实例上限。
