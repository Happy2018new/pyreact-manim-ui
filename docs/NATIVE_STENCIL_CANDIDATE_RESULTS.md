# Stencil 候选实机复测

这次在网易版 Windows OpenGL 3.10.0.467018 上用相同的 65,536 字节输入，常规视口为 720×1080，帧率上限为 60 FPS。各用例使用独立受管实例、被动 WGC 截图和全量数据读回。帧率上限是测试设置，本轮未采集性能数据。

## 独立粒子和普通特效

两个实际资源包顺序均验证通过。每个顺序中，16 项原生 FrameAni 画面对照通过，60 张数据诊断零错。有 32 张图同时验证序列帧与全量数据。两轮共 218 张截图中的额外包专有图样均准确，实际世界资源包 UUID 顺序确实反转。雨天也通过了完整数据、源符号和实际非 255 alpha 检查。

无额外包的首次画面对照受到镜头扰动。重新运行时相机固定，所有 56 张数据诊断零错，普通序列帧可见。16 项严格视觉检查中有 14 项通过。数据区内两项加法序列帧各有 8 个像素超过原验收公式的 3 级容差，最大差为 4。用相同场景下的原生画面直接比较，这两项的最大通道差均为 2。独立复算确认，先做原生加法混合、再走既有 6 bit 场景恢复的模型与三轮取样的 1,728 个 RGB 像素完全一致。验收公式使用恢复后的底色重新做混合，两个计算顺序会因量化得到不同结果。严格原判定仍保留未通过。

## 阴影

原版阴影读掩码 255 复现 196 个缺失阴影像素，全部对应 bit 64 被写入的位置。掩码 191 和 63 都保留了全部四类符号对应的阴影，受控场景的 20,378 个几何参照像素均在每通道误差 2 以内，完整数据和保护区零错。三组无载荷的画面对照也逐像素完全相等。191 只放宽对 bit 64 的检查，改动范围更小。原生阴影材料与其他效果共存还要单独验证。

## 维度与后处理

最初用原固定相机运行，在下界拿到接口成功回执但 65,280 字节读错，返回主世界后自动恢复。后续将相机和载体移到两维度均有效的正 Y 高度，只准备主世界脚下地形，下界保留自然地形。一次主世界进下界再返回的两张首次被动诊断图中，全部 65,536 字节和保护区精确匹配。后续逐源符号检查也零错。两次恢复复用了原有几何页，原生几何创建次数保持为 3。主世界 990 个测试位置均已恢复。这次补测没有验证连续往返、末地，也未单独证明早期低高度失败的成因。

原生景深首次复测的测试包把自定义材质写入了客户端未注册的文件。将定义合并进已加载的 `postprocess.material` 后，使用原生景深材质名及原生 shader 的参考用例通过。零模糊和恢复零模糊时，参考区 262,144 个 RGB 像素完全匹配。近景、远景和自动对焦的非零参数产生了独立的画面响应。

载荷开启后的零模糊和最后恢复零模糊，数据区与参考的逐通道差均在 2 以内，三种晚期诊断的 64 KiB 数据、恢复画面及诊断保护区均通过。静止场景严格对照仍未通过：两次独立世界单是零模糊就在外圈有 5,579 个差异像素，手动近景、远景、自动对焦在数据区内分别有 15,440、15,244、10,659 个像素超过容差。两次独立世界各自的零模糊与回零帧一致。跨世界的外圈差异全部落在地面，天空对应区域完全相同；有模糊时，数据区内超差像素也集中在地面侧的底部和侧边。现有对照不能分离底图差异与候选着色器差异，景深兼容性仍未关闭。

Bloom 的 T3 跨过程连接在材质注册修正后仍被拒绝。随后使用普通前序纹理的源对照绕开 T3，采集到六张真实截图，但截图依然显示原场景，白块未得到预期 RGB，alpha 也未从 255 切换到 0。源对照未通过，因此有原生 Bloom 的阶段没有启动。本轮对 Bloom 的执行和共存仍无法判定。

## 范围

本轮测试以 64 KiB Windows 实机为限。ADB 未检测到连接的设备，手机仍无实机结果。alpha 打包和 512 KiB 帧时间仍在后续验证范围。

各项状态、独立复算和清理回执见[证据索引](evidence/native-stencil-candidate-retest/summary.json)。


## 掩码 191 同屏与后续验证

- **晴天同屏通过。** 受管 720×1080 测试场景中，跨数据区边界的阴影、实体描边、方块填充高亮及矩形 UI 裁剪同时可见。两张同帧诊断中，分别检查 65,536 字节和 262,144 个源符号，数据和保护区零错。三种对象的全部预声明画面区域没有像素超过每通道误差 2。已按原门槛重跑，遮住了独立场景内自然活动的背景动物并在清理时恢复。
- **雨天通过数据和 UI。** 同一组数据与 UI 零错，源符号截图中有 4,328 个 alpha 非 255 的实测雨天像素。雨在各张参照之间移动，关闭 → 开启 → 关闭的画面稳定性检查未通过，阴影、描边和高亮的严格视觉比较仍未验收。
- **固定景深场景未取得截图。** 两套包已准备。测试在读取环境状态的第一步遇到 Windows 套接字资源不足错误 `WinError 10055`。固定房间、整幅零模糊外围门槛和非零配置的离线检查通过。
- **连续主世界／下界／末地未运行到传送。** 准备并启动了新用例，但系统可用提交内存约 2.46 GiB，低于加载门槛。此前单次下界往返结果仍可复现。新增脚本已准备好依次检查六次切换。
- **Bloom 未判定。** 三张新图源对照显示客户端拒绝编译图源里的 GLSL 保留字。已修正并重新生成两套测试包，原生光晕阶段仍待实际图源阳性之后再测。

同屏实机证据位于本机 `.runtime/native-stencil-combination-20261119-r1/shadow-joint-guard`。固定景深及连续维度的受管启动记录位于该目录树的 `dof-identity`、`dimensions` 两个用例子目录。当前结论适用于 64 KiB Windows 受控用例，尚不足以关闭全部视觉兼容性。
