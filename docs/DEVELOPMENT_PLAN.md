# 开发路线

## 优先级与交付范围

当前用户优先级是**尽快交付可用版本**：文字转换先行，配合可展示的二维 Manim 风格动画。2026-11-10 用户确认当前轮廓重合率已足够，要求停止继续研究像素差异；严格 1:1 暂不作为交付门槛，也不标记为已完成。本轮优先中文、宋体、系统字体选择和真实 LaTeX，不扩展 3D。

采用宿主 Python 离线执行受支持的场景定义、导出几何与时间数据、生成 shader 的路线。游戏只运行播放器，避免每帧解析字体或在玩家端安装桌面 Manim。

## 交付清单

| 内容 | 当前实现 | 关闭条件 |
| --- | --- | --- |
| 工程迁移 | 九项技能、调试脚本、MCP 配置、AGENTS 与 Pyreact 运行时已迁入 | 保持独立于投影业务；共享外部工具路径有记录 |
| 四组文字 | O → B、C → S、8 → 1、UI → UX | 构建成功，实机起终点及中间态可操作；近似样例在报告中明确标注 |
| 两组宋体中文 | 中文 → 变换、数学 → 中文 | 原生 Text 导出、字体覆盖检查、MC 中笔画和孔洞可见 |
| 两组 LaTeX | 分式换位、上标转根式 | 真正 Tex 排版，保留源码和 SVG，MC 起终点及中间态可操作 |
| 构建端字体选择 | 已安装字体名、显式字体文件、宋体 TTC | 不存在或缺字时明确报错；不偷偷回退字体 |
| 两组二维场景 | `basic_geometry`、`axes_sine` | 实机显示图形、曲线及运动，暂停/跳转后结果稳定 |
| 六个基础动画入口 | `Shift`、`Rotate`、`Scale`、`FadeIn`、`FadeOut`、`Transform` | 顺序/并行动画的状态和末态正确 |
| 曲线演示动画 | `Create`、`MoveAlong` | 线条逐段显现、点沿函数轨迹移动；不扩展为任意 Manim 动画兼容 |
| 播放面板 | 播放、暂停、进度拖动、三处定位、前后切例、Esc/F8 | 重开保留场景/位置；窄屏控件与画布不互相遮挡 |
| 一键静态构建 | `tools/build_demo.py --render-reference` 默认生成全部十例 | 输入可修改、生成可重复、资源校验后部署 |

文字一致性的三个层次——语义、数值误差、实机像素——仍按 [验收标准](ACCEPTANCE.md) 分别记录。默认文字与公式统一使用 Schema 2 并显式允许 marker 近似，属于预览；不以这些样例关闭全时间浮点一致性或语义片段匹配。

## 分阶段实施

| 顺序 | 工作 | 阶段结果与状态 |
| --- | --- | --- |
| 1. 初版集成收尾 | 六例构建、播放器生命周期、60 FPS 约束、画布与控件布局 | 96 项离线回归及后台实机 18 帧、640×360 布局通过；见 INITIAL_ACCEPTANCE.md |
| 2. 0.2.0 快速交付 | 合并已测有效的子像素/透明度修正；中文宋体、系统字体和真实公式 | 十例统一构建、后台实机与安装包；当前验收见 TEXT_FORMULA_ACCEPTANCE.md |
| 3. 按使用反馈补能力 | 字符/公式片段匹配、重复字符、增删及更多输入 | 每类有独立参考；现有普通 Transform 不代表语义匹配已实现 |
| 4. 独立 Pyreact 画布 | 页面内布局、裁剪、透明合成、遮挡、缩放、关闭清理、多实例 | 真正可嵌入的 UI 组件；全屏后处理预留空间不替代此项 |
| 5. 性能和可分发版本 | 场景预算、构建体积、分辨率、设备边界、错误提示与打包 | 有实际数据支撑的支持范围；手机需另行完成计时、输入与设备验证 |

二维基础能力已纳入初版，后续只在文字主线需要时补充。严格逐像素研究暂停；不为继续收敛边缘差异延迟交付，也不把图像指标当作项目完成百分比。

## 实机与性能规则

- 代理测试全部后台静默，使用挂起启动前安装的防激活保护；后台 SDK 状态操作和 WGC 截图不抢焦点。缺少保护时停止，不回退普通启动。见 [后台测试约定](BACKGROUND_TESTING.md)。
- 所有 MC 测试固定 **60 FPS**，不启用无限帧率。`tools/start_dev.py` 在启动前检查 Windows 原生 roaming 下的有效 options；修改前保留独立备份。
- 如果需要修改帧率配置且存在 MC 进程，启动器拒绝改写，不通过关闭其他会话来强行应用。配置已为 60 时不重复改写。
- 0.1.0 的六例测量作为历史记录保留；0.2.0 十例、30 张实机图和逐例播放已完成，见 TEXT_FORMULA_ACCEPTANCE.md。十次短时播放采样约 60.08 FPS，首次中文加载仍有明显等待，不能据此宣称全程无卡顿。
- 新版检查起点、中间态、终点、播放状态、切例、导航关闭和模拟 F8 事件重开，另修复并验证缩放后的物理视口刷新。真实按键交由人工复核，代理不激活游戏。
- CPU 预览、桌面 OpenGL 参考与 MC 截图分别保留。shader 编译成功或接口返回成功不等于画面通过。

## 定期整理与计划更新

每个阶段完成后进行小范围整理：固定 IR 与运行时契约，清理实验入口，减少重复路径，检查依赖归属，重跑关键字形和播放器回归。严格字形路线与预览近似需保留明确边界，不能靠兼容分支掩盖失败。

以实际验收关闭项更新后续估算。本轮没有继承旧投影项目的工期、额度、截止时间或休眠指令；“尽快初版”通过限制范围和优先集成实现，不虚构未经测量的完成日期。
