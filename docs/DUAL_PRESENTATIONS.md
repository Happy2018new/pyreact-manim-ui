# 两支原创作品：万象变换与风之童话

2026-11-10。当前修订为数学 V7、童话 V3。用户要求恢复复杂、彩色的数学演出，加入分形，并修复文字切断背景线条的问题；童话舍弃人物和具象场景，改为纯数学线条、流星、风与碎片重组的叙事。开头按用户示意采用左上／右下两行文字，先后淡入并发生轮廓变换，文字下方加入发光风线。完成后交用户直接观看，不另行执行画面验收。本轮参与修改的子代理统一为 gpt-6-astra / ultra。

## 影片与字体

两片均120秒、1920×1080、60 FPS，使用部署到游戏的 shader 与图集离线导出。MP4不是游戏录屏；游戏运行同一套 shader。原创配乐及音效由本地振荡器和噪声合成，没有外部音乐或采样。数学片沿用配乐；童话保留主题，增加两行开场风声、43秒流星撞击、碎片铃音与重组时逐步收拢的音色。

数学片所有英文标题、章节名与标签通过原生 ManimGL `Tex(\text{...}, template="basic")` 和 dvisvgm 排版，采用 LaTeX Computer Modern Roman；公式继续使用同一 LaTeX 工具链。中文使用 Noto Serif SC 宋体。童话画面没有额外英文文案。字体在构建端处理，玩家无需安装字体、LaTeX 或 Manim。

不同字形的转换现在提取并对应闭合外轮廓与孔洞，等弧长重采样后逐点连续移动。每个轨道最多256个点／分隔记录，源和目标坐标以16位形式存入现有图集下半区；新增与消失的轮廓在附近边界锚点展开、收拢。中间态使用环绕填充，端点回接原SDF。它属于有限点轮廓近似，不宣称等价于原生Manim的曲线拓扑或严格1:1。相同字形的空间运输仍保留，以提供节奏变化。

### 万象变换 V7

成片：`dist/client-showcase-v7/metamorphosis-fractal-chroma-120s.mp4`。前六版保留。21组文字／公式转换保留，其中18组含字形本体变化、3组身份运输；一般转换0.8秒，片尾1秒。

| 时间 | 当前演出 |
| --- | --- |
| 0–12秒 | 五股彩色对角线聚拢成投影参数结，变为花瓣后拉开为扇面；递归三角纹样随之逐级出现。 |
| 12–28秒 | 对应控制点路径从圆变方、三角、花瓣；加入折叠压缩、释放与透明棱面，颜色沿曲线流动。 |
| 28–48秒 | 带三层Sierpinski carpet的面积块拆分、转位、回拼；分形纹样始终跟随拼块，最后周界圆化。 |
| 48–66秒 | 同一圆周参数点逐段释放，圆周展开为正弦曲线，层间横肋形成扭转编织。 |
| 66–84秒 | 函数变为导数，黎曼矩形细分；积分面积和曲线颜色连续流动，最终收束到轮廓。 |
| 84–102秒 | 四条谐波依次并入合成波，合并后暂留低亮度分量，再收束为主波形。 |
| 102–114秒 | 彩色参数结展开为多层瓣形，带6、12、24阶径向细节、五层递归纹样与错拍收束／释放。 |
| 114–120秒 | 主体连续舒展为包围片名的大幅弧线，保留曲线完整性；文字变为中文片名并定格。 |

章节节拍与公式时间保持。分形结构采用固定五步逆向IFS，面积板采用三层Sierpinski carpet；最大活动几何预算为506条线段，没有新增纹理采样。颜色沿曲线参数和时间连续流动，青、紫、洋红与金色在形变中交替；主要轮廓保留亮度层次。这是实现预算，不是实机帧率验收结果。

V6的 `geoReadingMask` 在开头、高潮与结尾按文字矩形区域削掉整块背景曲线，是用户报告“字挡住背景数学线条”的明确源码原因。本版删除定义及全部调用，不用新的矩形遮罩替代。文字继续按字形覆盖率叠加，字间和孔洞外的背景线条不被文字包围盒截断。

### 风借来的一颗星 V3

成片：`dist/storybook-wind-v3/the-star-borrowed-by-the-wind-stardust-120s.mp4`，V1与V2保留。深色空间中的数学曲线、星核和碎片承担叙事，不再生成少女、村屋、纸船、森林或地形插画。

| 时间 | 情节与变换 |
| --- | --- |
| 0–18秒 | 第一行偏左上、第二行偏右下，依次缓慢淡入并展开字形；下方风线托住文字，第一行随后向金色星核收拢。 |
| 18–34秒 | 风线重构为轨道，星核醒来。 |
| 34–54秒 | 流星沿弧线逼近，43秒撞击；组成星核的固定身份碎片向外散开。 |
| 54–76秒 | 碎片沿连续风场与旋涡漂流，保持各自轨迹。 |
| 76–96秒 | 碎片依次沿弧线收拢，84.4秒首批归位，93.9秒完成重组，形成“灵魂重组”的核心演出。 |
| 96–110秒 | 完整光核再次绽开为星群，风与光重新舒展。 |
| 110–120秒 | 上一句字幕变为片名，结语“风起时，灵魂记得归途”从片名字形副本展开。 |

开场文字为“风，记得每一颗星的名字”与“也记得，它们回家的方向”。用户图中的红色矩形只用于定位，不绘制进影片；每句下方3条细长发光曲线同时是后续故事中风线的起点。两条完整星核曲线分成48个固定身份的相邻参数区间，破碎后再沿三次贝塞尔路径归位为双层六瓣光核，之后展开为四芒星；另有72颗固定编号星尘、3股流星尾迹和12条碎片回收尾迹。它们均由shader生成，没有使用外部图片或每帧随机重置的碎片位置。

开场两行按本轮明确要求同时使用淡入与轮廓变换。后续字幕在阅读期间完整保留，下一句到来时进行1.15秒的字形轮廓转换，再稳定停留，句间没有整句透明度淡入淡出；片名也参与变换。字幕与数学文字共用 `tools/presentation/vector_morph.py` 和 `.glsl`。

## 游戏内观看

主播放器右上角有“万象变换”“风之童话”两个入口。进入后右下角可切换另一片、暂停／继续、重播、返回；Esc返回播放器，F8可从游戏HUD重新打开播放器。退出后恢复原来的场景和暂停点。

音乐与音效位于 `resource_pack/sounds/pmanim/presentation/`，共240个独立命名OGG，总计约9.37MB。每片24个5秒基础段，每段还有4个整数秒起点尾段，支持暂停恢复和seek；仅停止本播放器启动的资源，遵从游戏主音量。

SDK没有公开的音频样本起点参数，恢复时向下选择整秒资源，理论偏差小于1秒，随后在5秒边界重新对齐；帧调度和解码可能增加延迟。没有宣称样本级同步或全设备无缝拼接。MP4使用连续完整音轨。

新轮廓点数据和shader必须配套刷新；更新游戏时重启本项目受管实例，保持后台不激活、固定60 FPS。其他对话的实例不在本项目操作范围内。既有窗口变化后0.75秒参数重试机制保留，本轮没有修改播放器逻辑。

## 重建

在已配置 `.venv-reference` 和固定字体源的本机工程根目录运行：

```powershell
.venv-reference/Scripts/python.exe -B -X utf8 tools/showcase_v2/build_type.py --output .runtime/showcase-v2
.venv-reference/Scripts/python.exe -B -X utf8 tools/build_presentations.py --math-assets .runtime/showcase-v2
.venv-reference/Scripts/python.exe -B -X utf8 tools/presentation/build_scores.py
.venv-reference/Scripts/python.exe -B -X utf8 tools/presentation/build_audio.py
.venv-reference/Scripts/python.exe -B -X utf8 tools/presentation/render_films.py
```

字体无变化时可直接运行不带 `--math-assets` 的 `build_presentations.py`，它从生产图集重新打包轮廓区。音轨已存在且没有修改时不必重新执行两个音频构建步骤。最终导出可用 `--scene client_showcase` 或 `--scene story_showcase` 单独运行；已存在同名文件需显式 `--overwrite`。

原始WAV、影片、封面与联系表放在忽略目录；游戏包不包含7200张视频帧。构建记录保存在 `tools/showcase_v2/film.json` 与 `tools/storybook/generated/story.json`；每支视频的 `.render.json` 包含部署资源、音轨和视频哈希。

## 状态边界

本轮进行交付所需的资源构建、GLSL编译与视频导出。按用户要求，不运行新版逐帧目检、完整测试套件或实机画面验收。游戏启动或SDK返回仅说明交付入口状态，不代表画面、听感或60 FPS实际性能验收。前版验收记录也不用于证明本版资源通过。
