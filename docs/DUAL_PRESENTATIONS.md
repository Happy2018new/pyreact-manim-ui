# 两支原创作品：万象变换与风之童话

2026-11-10。用户要求继续增强原演示，并另做一支童话般、带风特性的游戏开场视频；完成后直接交用户观察，不执行额外验收，需打开游戏且配乐可在游戏中听见。本轮子代理统一为 gpt-6.1-sol / ultra。

## 影片

两片均120秒、1920×1080、60 FPS，使用实际部署的 shader 与图集离线导出，配乐及音效由本地振荡器和噪声合成，无外部音乐或采样。MP4是离线作品视频，游戏播放同一套shader。

### 万象变换 V5

成片：`dist/client-showcase-v5/metamorphosis-cinematic-120s.mp4`，同目录有封面、分镜与 `.render.json` 导出记录。前四版保留。

公式章节、21组文字／公式转换、18组含字形本体形变及3组身份交换保留，普通转换0.8秒、片尾1秒。此次增强的是空间构图与释放节奏：

- 0–2.15秒：大轨道向镜头内收，形成靠近主体的空间感。
- 3.55／8.35秒：轨道沿折痕压缩，展开两侧透明光幕。
- 17.1／23.3秒：轮廓、游标与面片一起铰接折叠；17.65／23.85秒短促推近后回落。
- 33／38.3／43.55秒：公式下方形状靠拢、翻转，形成折带后展开。
- 105.65／109.7／112.45秒：几何聚能后释放倾斜光带与单调外扩的光环；保护中央公式阅读区。
- 114.2–117.5秒：三层环错开收束，119秒起几何静定。

音乐保留原曲结构，按公式转换增加轻微掠过声，在重要章节及高潮增加低频落点和光声。

### 风借来的一颗星

成片：`dist/storybook-wind-v1/the-star-borrowed-by-the-wind-120s.mp4`。原创剪纸童话，红斗篷少女与金色种子贯穿七幕，宋体短字幕辅助叙事。

| 时间 | 情节与视觉 |
| --- | --- |
| 0–16秒 | 失去星光的村落，一颗光点被风带向少女。 |
| 16–34秒 | 少女接住发光种子，斗篷、发尾与风带相互呼应。 |
| 34–54秒 | 纸船穿过分层云海，船的轮廓连续变成云。 |
| 54–76秒 | 暴风与黑森林；风的幅度、暗色层景和音效共同形成低谷。 |
| 76–96秒 | 种子落地、拉成长树干，枝条与光叶依次展开。 |
| 96–110秒 | 42片光叶从枝头各自展开成鸟翼，飞向星空。 |
| 110–120秒 | 片名与“每一次风起，都是星星回家的路”，最后一秒淡黑。 |

风直接改变斗篷边缘、发尾、云面、丝带、树梢和飞叶。船→云、种子→树、叶→鸟包含真实轮廓变化。风声、纸帆掠过、远雷、种子铃声和星鸟飞行音效与童话配乐合成在同一音轨。

源文件位于 `tools/storybook/`，独立宋体图集67字形约530KB。复用固定Noto Serif SC源和已有图集编译工具，生成字体子集随附SIL OFL许可；不要求玩家安装字体、LaTeX或Manim。

## 游戏内观看

主播放器右上角有“万象变换”“风之童话”两个入口。进入后右下角可切换另一片、暂停／继续、重播、返回；Esc返回播放器，F8可从游戏HUD重新打开播放器。退出后恢复原来的场景和暂停点。

音乐与音效位于 `resource_pack/sounds/pmanim/presentation/`，通过 `sound_definitions.json` 注册240个项目独立命名的OGG资源，总计约9.37MB。每片24个5秒基础段，每段还有4个整数秒起点尾段，支持暂停后恢复和seek；只停止本播放器已启动的资源，不修改全局音量或停止其他模组声音。

SDK没有公开的音频样本起点参数，恢复时向下选择整秒资源，理论音画偏差小于1秒，随后在5秒边界重新对齐；帧调度和解码也可能造成额外延迟。没有宣称样本级同步或所有设备无缝拼接。完整音轨在MP4中连续编码。游戏仍遵从原有主音量设置。

新增声音文件需完整客户端重启；本轮启动新的项目受管实例。按既有约定保持后台不激活、60 FPS，不接管其他对话的游戏。

准备播放入口时发现 resize 紧邻的后处理参数提交失败。客户端现为窗口变化保留0.75秒的有限恢复期，期间清缓存并在下一帧重试；持续失败不延长截止，超时仍报原错误并隐藏，不进行无限重试。保留原始SDK返回与恢复诊断。这是启动过程中发现并处理的问题，未另做缩放回归验收。

## 重建

在已配置 `.venv-reference` 和固定字体源的本机工程根目录依次运行：

```powershell
.venv-reference/Scripts/python.exe -B -X utf8 tools/build_presentations.py
.venv-reference/Scripts/python.exe -B -X utf8 tools/presentation/build_scores.py
.venv-reference/Scripts/python.exe -B -X utf8 tools/presentation/build_audio.py
.venv-reference/Scripts/python.exe -B -X utf8 tools/presentation/render_films.py
```

最后一步输出两支视频，已有文件需显式 `--overwrite`；可用 `--scene client_showcase` 或 `--scene story_showcase` 单独导出。原始WAV仅保留在忽略的 `.runtime/presentation-audio/`。游戏包只包含OGG与实际shader／图集，不包含7200张视频帧。
