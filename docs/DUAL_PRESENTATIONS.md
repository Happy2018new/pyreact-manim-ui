# 双片光谱修订：万象，始于一线／风的回信

2026-11-10。用户指出数学 V8／童话 V4 相比早期版本过于简单，要求继续修改。本轮对照早期联系表，恢复复杂曲线、色彩层次、连续运动和公式展示强度；通过共同的参数、轨道与节奏把多层结构组织起来。三个开发子代理均使用 gpt-6-astra / ultra，分别负责数学几何、童话几何和配乐。

旧版数学 V1–V8、童话 V1–V4 的视频保留在各自 dist 目录。当前成片是数学 V9、童话 V5，均为120秒、1920×1080、60 FPS，带连续原创配乐。它们从当次游戏生产 shader 和图集离线导出，不是游戏录屏。

后续全屏性能修订已重建游戏资源：复用时间不变量、对曲线分组剔除、为整句字形生成边界，并更新通用 IR 编译器。原有复杂曲线、采样数量、字体和时间轴保留。本轮按用户要求未启动游戏复测，也未重出视频，因此上述 MP4 与导出哈希保留为优化前的视觉版本参考；当前 shader 与静态验证证据见 [性能说明](PERFORMANCE.md)。

## 数学片：万象，始于一线

成片：`dist/client-showcase-v9/from-a-line-to-infinity-120s.mp4`。

本版以青蓝、洋红、紫罗兰、金色组织多层光谱线。主曲线、相位错开的次曲线、旋转构造线和运动光点共同演变；细节在递归和高潮中逐步增加。公式使用更大的共享基线排版，Koch 章居中，谐波与曲面章置于上方，环面结与分形章置于下方，以避开密集交叉；图形保持连续，通过构图、色彩和亮度建立主次。

| 时间 | 分镜目的 |
| --- | --- |
| 0–14秒 | 两行宋体依次淡入与轮廓成长；流线、轨道和色彩运动建立开场。 |
| 14–34秒 | 多层相位错开的内旋轮线、玫瑰曲线与环面结持续形变，辅以旋转构造环。 |
| 34–54秒 | 四层 Koch 递归生成，祖先轮廓与旋转轨迹形成层次，局部推近再回归。 |
| 54–74秒 | 旋转圆展开为波列，可见谐波轮和多层波形表现叠加过程。 |
| 74–96秒 | 多条纵线与横向连接组成编织曲面，持续折叠为曲面花冠。 |
| 96–112秒 | 旋转、呼吸和光谱色流中的递归六角分形，与构造环共同形成高潮。 |
| 112–120秒 | 曲线收束，中文标题完成形变，保留流动的结尾框景。 |

五个公式章节共14次真实字形形变，另有结尾中文标题形变，每次0.6秒，目标公式保持3–6秒。本轮调整排版与色彩，并重新打包对应点数据，复用既有字体源。所有英文与公式沿用原生 LaTeX Computer Modern，中文使用宋体。

旧版 `geoReadingMask` 的矩形挖空曾使文字附近背景线条中断。本版继续禁止任何文字矩形遮罩，字间和孔洞的背景几何保持连续；通过布局与几何亮度控制可读性。

## 童话片：风的回信

成片：`dist/storybook-wind-v5/a-letter-from-the-wind-120s.mp4`。

故事以曲线星核、编织风流和持续对应的曲线碎片承担叙事，不包含人物、房屋、树木或地形。主体以玫瑰／内旋轮线和轨道细节形成有层次的轮廓，青蓝与紫色风流围绕金色核心运动。曲线碎片在破碎、漂流、旋转、归位和展开过程中保持身份，光翼由连续弯曲线束构成。

| 时间 | 分镜目的 |
| --- | --- |
| 0–16秒 | 两行宋体错位依次呈现，淡入加轮廓成长；下方编织流风接入故事。 |
| 16–32秒 | 层叠曲线星核在风中展开，轨道、光点和花形线束共同运动。 |
| 32–43秒 | 流星与多层尾迹沿弧线接近，43秒冲击星核。 |
| 44–64秒 | 同一组曲线单元破碎为卷曲彗星状碎片，在风中分层漂流。 |
| 64–78秒 | 风流变成旋涡，碎片与光点沿多层轨道回旋。 |
| 78–94秒 | 碎片沿弧线归位，重建带有细密曲线的星核与光冠。 |
| 94–110秒 | 光冠展开为弯曲的光翼和光带，形成重组后的释放。 |
| 110–120秒 | 曲线光翼形成结尾框景，片名与结语稳定停留。 |

后续叙事字幕仍使用轮廓连续变换，保留阅读时间；仅开头使用用户指定的整句淡入。所有文案由固定宋体源构建。字幕、标题与几何的时间和布局以 `tools/storybook/generated/story.json` 为准。

## 公共文字变换与边界

两片共用 `tools/presentation/vector_morph.py` 和 `.glsl`。字形外轮廓与孔洞经过分层匹配、等弧采样和对应点插值，端点使用原SDF；新增与消失的组件通过几何收拢、展开处理。

V8／V4 已修复外轮廓和孔洞合并后取绝对环绕数导致游离孔洞被填白的问题。本版保留该修复：图集分隔记录保存外壳／孔洞角色，逐轮廓计算覆盖率、将孔洞限制在其所属外壳内，再合并组件；同时处理退化轮廓与孔洞锚点。内部格式为schema 2，仍使用每轨最多256个记录。数学／童话图集必须与shader配套构建。

轮廓中间态仍是固定点数的多边形近似，不宣称原生Manim曲线拓扑或严格1:1。LaTeX与字体只在构建端使用，玩家无需安装这些工具。

## 音乐与游戏

两条120秒配乐使用本地振荡器与原创音序，无外部音乐或音色采样。数学片保留80 BPM，加强温暖低音、错位节奏与立体声晶体音色，在96–104秒加速蓄力，104秒释放后继续推进至112秒。童话片保留90 BPM，增加移动风声、流星掠过和旋涡音型，保护43秒撞击后的近静音，78–94秒逐层蓄力，94秒展开宽阔和声。音轨为48kHz立体声，峰值保留约1.5dB余量。

游戏主播放器有“万象变换”和“风之童话”入口，场景列表显示当前完整片名。进入后支持暂停／继续、重播、片内切换、返回。Esc返回播放器，F8从HUD重新打开。准备交付时仅操作本项目 `manim-dual-presentation` 受管实例，后台不激活，配置60 FPS上限。

游戏音乐使用240个独立命名OGG：每片24个5秒段，每段附4个整数秒起点尾段，支持暂停和seek。恢复时向下选择整秒尾段，理论偏差小于1秒，解码与调度还可能增加延迟；没有样本级同步保证。MP4使用连续整条WAV。游戏遵从主音量，停止时只停止本播放器的声音。

## 重建

在已配置字体、LaTeX和参考虚拟环境的本机工程根目录运行：

```powershell
.venv-reference/Scripts/python.exe -B -X utf8 tools/build_presentations.py
.venv-reference/Scripts/python.exe -B -X utf8 tools/presentation/build_scores.py
.venv-reference/Scripts/python.exe -B -X utf8 tools/presentation/build_audio.py
.venv-reference/Scripts/python.exe -B -X utf8 tools/presentation/render_films.py
```

既有字体源可直接从生产图集重新打包轮廓区。新增字形时先执行 `tools/showcase_v2/build_type.py --output <assets>`，再向总构建入口传入 `--math-assets <assets>`。单片导出使用 `--scene client_showcase` 或 `--scene story_showcase`；同名输出已存在时需显式 `--overwrite`。片名注册读取童话manifest。

源码和小型manifest保存在Git；dist影片、原始WAV、封面和联系表存于忽略目录。每支视频的 `.render.json` 记录shader、图集、音轨与视频的哈希，构建元数据位于 `tools/showcase_v2/film.json` 和 `tools/storybook/generated/story.json`。

## 状态说明

本轮根据早期版本与V8／V4的联系表比较修订设计，查看新版关键帧并修正了环面结／分形与公式相互拥挤的排版。构建、GLSL编译、时间轴检查与视频导出用于生成可播放交付物；完整审美与听感验收交由用户。没有将新版标记为完整视觉验收、实机性能验收或严格1:1通过。后台启动和播放器状态仅确认观看入口就绪，配置60 FPS上限不代表已测得每个场景持续60 FPS。
