# 双片重制：万象，始于一线／风的回信

2026-11-10。用户否定此前两片的整体观感，要求全部重做。本轮重写分镜、几何、排字和音乐，不以增加旧画面的装饰密度为目标。最新协作模型为 gpt-6.1-sol / ultra；切换前参与的 gpt-6-astra 代理已中断，后续代理接续已保存的修改。

旧版数学 V1–V7、童话 V1–V3 的视频保留在各自 dist 目录。当前成片是数学 V8、童话 V4，均为120秒、1920×1080、60 FPS，带连续原创配乐。它们从游戏生产 shader 和图集离线导出，不是游戏录屏；游戏播放同一套资源。

## 数学片：万象，始于一线

成片：`dist/client-showcase-v8/from-a-line-to-infinity-120s.mp4`。

本版用一个清晰主对象贯穿每个段落，奶白主线、青绿次色和珊瑚金建立层次；紫罗兰用于高潮。主轮廓和局部半透明面共同形成形体。递归结构有生成与变化的过程，避免全片彩虹细线叠加。公式在边缘排版，并与几何过程对应。

| 时间 | 分镜目的 |
| --- | --- |
| 0–14秒 | 左上“从一条线”、右下“到无穷万象”依次淡入、展开轮廓；下方细线接入主图形。 |
| 14–34秒 | 大圆描绘为花冠与投影结，强调同一条曲线的对应点变化。 |
| 34–54秒 | Koch雪花递归逐层生成，局部推近，再重新合拢。 |
| 54–74秒 | 复平面中的旋转点将圆展开为波形，谐波逐步合成。 |
| 74–96秒 | 同一组曲线继续成为大幅折叠曲面与花冠。 |
| 96–112秒 | 主体汇聚并展开为分形星，建立全片高潮。 |
| 112–120秒 | 几何回到线与稳定的大标题，留出阅读时间。 |

本版重建文字时间轴与字体图集，原21组转换数量不再作为当前作品的验收断言。五个公式章节共14次真实字形形变，另有结尾中文标题形变，每次0.6秒，目标公式保持3–6秒。所有英文与公式沿用原生 LaTeX Computer Modern，中文使用宋体。

旧版 `geoReadingMask` 的矩形挖空曾使文字附近背景线条中断。本版继续禁止任何文字矩形遮罩，字间和孔洞的背景几何保持连续；通过布局与几何亮度控制可读性。

## 童话片：风的回信

成片：`dist/storybook-wind-v4/a-letter-from-the-wind-120s.mp4`。

故事以大星核、有面积的几何瓣片和流风带承担叙事。画面是二维几何插画与曲线变换，不包含人物、房屋、树木、地形。主对象具有清晰尺寸和明暗层级，风以有宽窄的丝带与线核呈现。

| 时间 | 分镜目的 |
| --- | --- |
| 0–16秒 | “如果星光散落”与“风会替它记住归途”按左上／右下布局依次呈现，使用淡入加字形轮廓变换。下方青金风带连接后续故事。 |
| 16–32秒 | 风托起大幅奶白六角星核；双层几何瓣片组成可辨识的完整形体。 |
| 32–43秒 | 长流星沿弧线接近，43秒击中星核。 |
| 44–64秒 | 同一批24片几何瓣片散开、随风分层漂流，破碎前后保持对应。 |
| 64–78秒 | 风从混乱漂流中形成轨道与节拍，建立转机。 |
| 78–94秒 | 原碎片沿弧线逐片归位，形成双层十二瓣光冠。 |
| 94–110秒 | 光冠绽开为长光翼与完整星核，完成重组后的释放。 |
| 110–120秒 | 光翼收为框景，中央大标题与结语稳定停留。 |

后续叙事字幕仍使用轮廓连续变换，保留阅读时间；仅开头使用用户指定的整句淡入。所有文案由固定宋体源构建。字幕、标题与几何的时间和布局以 `tools/storybook/generated/story.json` 为准。

## 公共文字变换与边界

两片共用 `tools/presentation/vector_morph.py` 和 `.glsl`。字形外轮廓与孔洞经过分层匹配、等弧采样和对应点插值，端点使用原SDF；新增与消失的组件通过几何收拢、展开处理。

上一版渲染器把外轮廓和孔洞合并后用绝对环绕数填充，会把变形过程中游离到外轮廓之外的负向孔洞画成白色实体。本轮在图集分隔记录中保存外壳／孔洞角色，逐轮廓计算覆盖率、将孔洞限制在其所属外壳内，再合并组件；同时处理退化轮廓与孔洞锚点。图集内部格式升为schema 2，仍使用每轨最多256个记录。数学／童话图集必须与更新后的shader一起重建，不能只替换公共shader。

轮廓中间态仍是固定点数的多边形近似，不宣称原生Manim曲线拓扑或严格1:1。LaTeX与字体只在构建端使用，玩家无需安装这些工具。

## 音乐与游戏

两条120秒配乐按新分镜重写，使用本地振荡器、合成噪声和原创音序，无外部音乐或音色采样。数学片以80 BPM的脉冲、木质键音和弦感铺底推进；童话片以90 BPM的温暖拨弦与合唱样铺底形成旅程，在43秒撞击、78–94秒重组和94秒绽放处安排转折。音轨为48kHz立体声，峰值保留约1.5dB余量。

游戏主播放器有“万象变换”和“风之童话”入口，场景列表显示当前完整片名。进入后支持暂停／继续、重播、片内切换、返回。Esc返回播放器，F8从HUD重新打开。准备交付时仅操作本项目 `manim-dual-presentation` 受管实例，后台不激活，配置60 FPS上限。

游戏音乐使用240个独立命名OGG：每片24个5秒段，每段附4个整数秒起点尾段，支持暂停和seek。恢复时向下选择整秒尾段，理论偏差小于1秒，解码与调度还可能增加延迟；没有样本级同步保证。MP4使用连续整条WAV。游戏遵从主音量，停止时只停止本播放器的声音。

## 重建

在已配置字体、LaTeX和参考虚拟环境的本机工程根目录运行：

```powershell
.venv-reference/Scripts/python.exe -B -X utf8 tools/showcase_v2/build_type.py --output .runtime/showcase-v8
.venv-reference/Scripts/python.exe -B -X utf8 tools/build_presentations.py --math-assets .runtime/showcase-v8
.venv-reference/Scripts/python.exe -B -X utf8 tools/presentation/build_scores.py
.venv-reference/Scripts/python.exe -B -X utf8 tools/presentation/build_audio.py
.venv-reference/Scripts/python.exe -B -X utf8 tools/presentation/render_films.py
```

字体源和排版无变化时可直接从生产图集重新打包轮廓区。单片导出使用 `--scene client_showcase` 或 `--scene story_showcase`；同名输出已存在时需显式 `--overwrite`。片名注册读取童话manifest，不再硬编码前版名称。

源码和小型manifest保存在Git；dist影片、原始WAV、封面和联系表存于忽略目录。每支视频的 `.render.json` 记录shader、图集、音轨与视频的哈希，构建元数据位于 `tools/showcase_v2/film.json` 和 `tools/storybook/generated/story.json`。
