# 0.1.0 预览版验收记录

本轮完成可修改、可构建和可操作的二维演示。文字 1:1 是后续仍需完成的验收目标，不能由本初版的通过项替代。

## 已实现并验证

- 工程迁入九项技能、受管调试脚本、项目 agent 约定和 Pyreact 运行时；未修改旧投影业务。
- 一条完整构建路径：静态 Python → 真实 ManimGL 文字数据／二维场景 → 数据纹理与 shader → 游戏资源及播放器。
- 六例：O→B、C→S、8→1 预览、UI→UX 预览、二维图形动画、坐标轴正弦曲线动画。
- 二维图元：圆、矩形、多边形、点、线段、折线、箭头、坐标轴、函数曲线。
- 动画：移动、旋转、缩放、淡入、淡出、多边形变形、曲线逐段绘制、沿路径移动；支持按顺序与不同对象并行编排。
- 播放面板：播放／暂停、进度定位、起点／中间态／终点、上一例／下一例、关闭清理和重开保留状态。

## 图像一致性边界

MC 与同一生成 shader 的桌面 OpenGL 对照覆盖 12 张文字定点图，前景 IoU 约 99.9964%～100%，前景通道平均差约 0.00015～0.27012/255。它验证数据与绘制进入 MC 的通路，**不是与 Manim 1:1 的结论**。

真实 ManimGL Camera 对照独立保留，四例每例五帧。O→B、C→S 仍有曲线采样和抗锯齿差异；补全原生细边层后的 8→1 前景 IoU 约 97.31%～99.03%，UI→UX 约 98.72%～99.45%。两例显式允许极窄浮点 skip 时间窗的近似；没有声称全时间相等。上述百分比是指定帧的图像指标，不是项目完成度。
