# PyreactMC integration in pyreact-manim-ui

Imported from the existing better-building-editor integration, based on upstream
`9580d0123584ae8b4b4b3a7b0357250e151c54cd`. The inherited modifications are documented
in `UPSTREAM.md`; those historical descriptions do not describe this demo's features.
The Python framework is copied without changes at this import. The matching
`resource_pack/ui/PyreactBase.json` removes the old application's `ModernProjection.*`
template references. No building editor business code or world data is included.

The complete custom LICENSE and NOTICE remain in this directory. This is a modified
integration, not an official upstream release. 本项目使用 PyreactMC 客户端 UI 框架。
