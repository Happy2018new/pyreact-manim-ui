# 风的回信

120秒、1920×1080、60 FPS的原创几何线条童话。大幅奶白星形、青绿与暖金风带、少量珊瑚色瓣片构成主画面。星光破碎后，24片有面积的闭合几何碎片沿风漂流，再归为双层十二瓣光冠，最后舒展为左右光翼。画面使用参数曲线、四顶点几何面和真实宋体字形轮廓；主体不使用人物、建筑、树木、地形或风景插画。音乐、音效与视频导出由工程集成入口同步处理。

工程根目录构建命令：

```powershell
.venv-reference/Scripts/python.exe -B -X utf8 tools/storybook/build_film.py
```

构建更新本目录 `generated/`、`resource_pack/shaders/glsl/story_showcase.fragment` 和 `resource_pack/textures/manim/story_showcase.png`。场景ID保持 `story_showcase`，片名由生成清单提供。数学片、播放器、场景注册、材质及音轨属于其他构建环节。

开头第一行“如果星光散落”位于左上 `(-2,1.5)`，第二行“风会替它记住归途”位于右下 `(1.8,-1)`，宋体字高约 `.65`，最大宽度分别为 `8.6`、`9.8`。第一句1.0–4.4秒、第二句5.3–8.7秒逐字展开真实轮廓，并分别在前2秒淡入。三条有宽窄变化的青金风带从左上文字下方延伸到右下文字下方。第一句12–16秒收拢到 `(-1.2,.45)`；星核在同一锚点生长，16–24秒移向 `(0,.45)`。第二句16秒变为底部叙事字幕。

主体时间轴如下：

| 时间 | 连续动作 |
| --- | --- |
| 0–16秒 | 两行大宋体依次展开；三条青金风带连接两行，第一句轮廓收拢成星光。 |
| 16–32秒 | 风带托起双层六角星。外层直径4.3场景单位，约占完整画面高48%、电影内容区高57%；闭合瓣片有半透明填充与清晰奶白边线。 |
| 32–43秒 | 左上长流星沿弧线进入；奶白主尾与金青副尾沿运动方向渐细，43.0秒撞击星核。 |
| 43–50秒 | 冲击光环扩散，原星形的24片几何面分别旋转、缩放并沿贝塞尔路径飞散。 |
| 50–64秒 | 同一批碎片分层漂流，风带横穿画面，固定颜色与编号保留各片身份。 |
| 64–78秒 | 风带弯成开口轨道，碎片逐步进入不同半径的回旋节拍。 |
| 78–94秒 | 24片碎片依次沿三次贝塞尔弧线归位。启动时间由78秒均匀延至87秒，每片回收7秒，最后一片在94秒完成；对应顶点同时重组为双层十二瓣光冠。 |
| 94–110秒 | 外层12片展开为左右各6片长光翼；内层12片保留中央光冠。104–110秒，中央光冠上移并缩为片名上方的几何徽记，光翼随之抬起框景。 |
| 110–120秒 | 叙事字幕轮廓变为大标题“风的回信”；113.4秒结语“风会记住，每一束光”从标题附近的轮廓锚点展开。光翼、下方青金风带与中央小光冠共同保留画面。 |

星形初态的每层包含12片相邻扇形四边面。破碎、漂流、回收与光翼展开使用同一24个编号及每片4个对应顶点，时间只推进连续位置、旋转与形变。最终内层光冠和外层光翼都来自原来的碎片。所有几何面在边缘距离、填充和辉光运算前按自身包围盒裁剪。风带共3条，每条36段；回收尾迹仅8条、每条12段；流星3股尾迹、每股20段；背景为32个小圆点。线宽与局部填充共同形成主体面积，辉光采用解析衰减。

后续字幕转换持续1.15秒，前句保留到下一次转换开始。共用 `tools/presentation/vector_morph.py` 对字形的外轮廓、组件和洞做匹配，再以等弧样本逐点变形；缺失组件从锚点展开或收拢。整句透明度保持为1，仅开场按上文时间淡入。片名、结语也使用字形轮廓转换。端点使用原宋体SDF，中段由公共轮廓模块生成闭合多边形；本片不声称与Manim原生Transform逐像素相同。

渲染输入沿用现有约定：`EXTRA_VECTOR1=(时间秒,物理画布宽高比,物理画布像素高,不透明度)`，`EXTRA_VECTOR2=(翻转Y,顶部比例,高度比例,保留)`。`TEXTURE_0` 为原画面，`TEXTURE_2` 为4096图集。上半部存宋体SDF，下半部存源/目标轮廓的16位XY数据。字形采用Point/Clamp和手动双线性采样，点数据直接读取。16:9时坐标范围为x±8、y±4.5，电影内容区为y±3.75；字幕基线附近的中心为 `(0,-3.05)`，为主体保留空间。

字体来自工程缓存的固定Noto Serif SC官方源，400字重子集和SIL OFL1.1许可随生成目录保留。画面文案全部中文；若以后添加英文，必须沿用固定LaTeX字体流程。旧插画资产已退出构建。此版本未新增素材或依赖。

本轮资源重建不启动游戏、不录制、不导出视频，也未执行截图或人工验收。统一构建、配乐和最终视频导出由工程集成层执行。
