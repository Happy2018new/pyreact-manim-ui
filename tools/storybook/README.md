# 风的回信

120秒、1920×1080、60 FPS的原创数学线条童话。大幅青蓝、紫与洋红花丝围绕暖金星核流动，三股编织光流承托主角。星光破碎后，原有24束闭合花瓣曲线缩成彗星花种，携带细尾迹和72粒小彗星漂流，卷入多圈涡流后再归为数学玫瑰，最后舒展为弯曲的极光羽翼。画面使用谐波参数曲线、极坐标玫瑰、倾斜轨道与真实宋体字形轮廓；主体不使用人物、建筑、树木、地形或风景插画。音乐、音效与视频导出由工程集成入口同步处理。

工程根目录构建命令：

```powershell
.venv-reference/Scripts/python.exe -B -X utf8 tools/storybook/build_film.py
```

构建更新本目录 `generated/`、`resource_pack/shaders/glsl/story_showcase.fragment` 和 `resource_pack/textures/manim/story_showcase.png`。场景ID保持 `story_showcase`，片名由生成清单提供。数学片、播放器、场景注册、材质及音轨属于其他构建环节。

开头第一行“如果星光散落”位于左上 `(-2,1.5)`，第二行“风会替它记住归途”位于右下 `(1.8,-1)`，宋体字高约 `.65`，最大宽度分别为 `8.6`、`9.8`。第一句1.0–4.4秒、第二句5.3–8.7秒逐字展开真实轮廓，并分别在前2秒淡入。三股有宽窄变化、内部交织和流动光包的青紫风流，从左上文字下方延伸到右下文字下方。每股包含13条细丝和一条更明亮的中央脊线。第一句12–16秒收拢到 `(-1.2,.45)`；星核在同一锚点生长，16–24秒移向 `(0,.45)`。第二句16秒变为底部叙事字幕。

主体时间轴如下：

| 时间 | 连续动作 |
| --- | --- |
| 0–16秒 | 两行大宋体依次展开；三股39丝光流连接两行，第一句轮廓收拢成星光。 |
| 16–32秒 | 双层24束曲线花瓣展开，每束携带7条花丝；极坐标玫瑰、三族倾斜轨道和金色同心环交叠，形成大幅有呼吸感的星魂。外部直径约5.2场景单位，占完整画面高约58%、电影内容区高约69%。 |
| 32–43秒 | 左上长流星沿弧线进入；暖金主尾和9股青紫编织尾迹沿运动方向渐细，43.0秒撞击星核。 |
| 43–50秒 | 多层冲击光环扩散，原有24束花瓣分别旋转、缩放并沿贝塞尔路径飞散；72粒小彗星从星核向三层轨道扩张。 |
| 50–64秒 | 同一批曲线花种分层漂流，尾迹延续各片运动。三股多丝风流不断起伏、编织，彩色光包沿线行进；固定颜色与编号保留原花瓣身份。 |
| 64–78秒 | 三股风流连续卷为各自超过一圈的螺旋，花种进入不同半径的回旋节拍，细彗星以不同角速度绕行。 |
| 78–94秒 | 24束花丝依次沿三次贝塞尔弧线归位。启动时间由78秒均匀延至87秒，每束回收7秒，最后一束在94秒完成；同一组曲线连续恢复尺度并形变为更丰盛的数学玫瑰。 |
| 94–110秒 | 外层12束展开为左右各6片弯曲、圆润的极光羽翼；内层12束保留中央花冠。104–110秒，花冠上移并缩为片名上方的曲线徽记，羽翼随之抬起框景。 |
| 110–120秒 | 叙事字幕轮廓变为大标题“风的回信”；113.4秒结语“风会记住，每一束光”从标题附近的轮廓锚点展开。多丝羽翼、下方编织光流与中央金色星核继续缓慢流动。 |

星魂初态的每层包含12条闭合谐波花瓣曲线。破碎、漂流、回收与光翼展开使用同一24个编号与对应曲线参数，时间推进连续位置、旋转、尺度和形状插值。每条主曲线周围以最近点距离重复生成7条花丝，因此最终内层花冠和外层羽翼都来自原来的曲线碎片。主线更明亮、细丝保留饱和色，暖金只集中在核心、少量花瓣及主风脊；15条低亮度深度线与稀疏星点承托空间。

每条花瓣32段，先裁剪整条曲线包围盒，再裁剪局部线段。三股风流各52段，13条细丝共享一次最近曲线查询；流星9股尾迹共享28段。漂流与回收尾迹最多24条、每条10段，按章节和邻近范围裁剪。三族轨道共21丝、玫瑰纹饰11丝与15条深度线均用解析重复场求值；72粒小彗星分布在三层角度单元，每像素只重建3个最近单元。背景星点同样只查询一个稀疏网格单元。细丝数量不增加逐丝距离循环，辉光使用解析衰减，色调映射保留发光层次。

后续字幕转换持续1.15秒，前句保留到下一次转换开始。共用 `tools/presentation/vector_morph.py` 对字形的外轮廓、组件和洞做匹配，再以等弧样本逐点变形；缺失组件从锚点展开或收拢。整句透明度保持为1，仅开场按上文时间淡入。片名、结语也使用字形轮廓转换。端点使用原宋体SDF，中段由公共轮廓模块生成闭合多边形；本片不声称与Manim原生Transform逐像素相同。

渲染输入沿用现有约定：`EXTRA_VECTOR1=(时间秒,物理画布宽高比,物理画布像素高,不透明度)`，`EXTRA_VECTOR2=(翻转Y,顶部比例,高度比例,保留)`。`TEXTURE_0` 为原画面，`TEXTURE_2` 为4096图集。上半部存宋体SDF，下半部存源/目标轮廓的16位XY数据。字形采用Point/Clamp和手动双线性采样，点数据直接读取。16:9时坐标范围为x±8、y±4.5，电影内容区为y±3.75；字幕基线附近的中心为 `(0,-3.05)`，为主体保留空间。

字体来自工程缓存的固定Noto Serif SC官方源，400字重子集和SIL OFL1.1许可随生成目录保留。画面文案全部中文；若以后添加英文，必须沿用固定LaTeX字体流程。旧插画资产已退出构建。此版本未新增素材或依赖。

本轮资源重建不启动游戏、不录制、不导出视频，也未执行截图或人工验收。统一构建、配乐和最终视频导出由工程集成层执行。
