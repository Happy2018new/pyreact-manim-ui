# 风借来的一颗星

独立原创童话开场，120秒、1920×1080、60 FPS。以深靛夜空、青绿层景、珊瑚斗篷和金色细线讲述少女与发光种子的旅程。场景和人物使用原创贝塞尔曲线插画，字幕为固定400字重宋体；没有额外英文画面文案。

在工程根目录运行：

```powershell
.venv-reference/Scripts/python.exe -B -X utf8 tools/storybook/build_film.py
```

构建只更新本目录 `generated/`，以及独立的生产 shader 和贴图：

- `resource_pack/shaders/glsl/story_showcase.fragment`
- `resource_pack/textures/manim/story_showcase.png`

不修改数学片、播放器、场景注册、材质或音频。场景与材质由集成层注册。

渲染输入沿用现有后处理约定：`EXTRA_VECTOR1=(时间秒,物理画布宽高比,物理画布像素高,不透明度)`；`EXTRA_VECTOR2=(翻转Y,顶部比例,高度比例,保留)`。`TEXTURE_0` 是原画面，`TEXTURE_2` 绑定宋体图集（Point/Clamp，shader手动双线性）。宽高比16:9时世界范围为x±8、y±4.5；内部为2.18:1电影宽幅构图，字幕处于画面内部。

七幕分别为0–16失星村落、16–34掌心种子、34–54云海纸船、54–76暴风森林、76–96星光生根、96–110光叶归鸟、110–120片名。`generated/story.json` 给出字幕、章节、字体/资源哈希与参数说明。七幕处于同一个连续世界：坡地抬升成云海，村落移出及回到坡地，人物连续移动，场景之间没有整幅交叉淡化。

`build_art.py` 保存人工设计的曲线轮廓：约5–6头身的侧脸少女、弯曲手臂和手掌、流动发丝与斗篷、裙摆和靴子、弧形屋顶、弧形帆船与树干。曲线离线采样成有边界裁剪的多边形。房屋增加拱窗、墙面分色和坡地前后层次，云海增加卷曲线条，森林使用曲率和渐细枝干。

18条有固定身份的三次贝塞尔曲线贯穿全片。每条曲线的对应控制点连续重构为风、帆/船、波浪、森林枝干、光树、鸟翼和星图。叶→燕→星另用64点等弧长闭合轮廓逐点插值，不再混合不同对象的距离场。

所有字幕保留到下一句开始转换；转换持续1.15秒，之后完整停留。首句由各字的零面积轮廓长出，后续使用共用 `tools/presentation/vector_morph.py` 对字形闭合轮廓做组件/洞匹配、等弧采样与对应点插值。出现或消失的组件在锚点展开或收拢，不对整句做透明度渐变。片名由最后一句字幕重构并移至画面中央，结语从片名字形的副本展开。端点使用原宋体SDF，中间使用最多256点的轮廓近似；该效果不声称是Manim原生Transform的逐像素复刻。

字体使用工程已缓存的固定Noto Serif SC官方源，源SHA256见构建脚本。`setup_cjk.build_subset` 以fontTools4.62.1实例化400字重并重命名为Pyreact Manim Song；独立字体子集和SIL OFL1.1许可放在generated目录。图集编译复用现有`tools/showcase_v2/build_type.py`。4096图集上半部存静态宋体SDF，下半部存16位XY编码的源/目标轮廓点；仍只绑定现有TEXTURE_2。不需要新依赖或新图片素材，不覆盖数学图集。当前画面全部中文；若增加英文，应使用工程固定LaTeX字体流程。

本构建不运行游戏、录制、导出视频或执行实机验收。音轨、最终视频导出和播放注册由集成层完成。
