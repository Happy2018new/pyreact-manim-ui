# 风借来的一颗星

120秒、1920×1080、60 FPS的原创抽象线条童话。深色空间中的风、星核、流星、碎片和星尘完成一次灵魂重组。画面全部由参数曲线、连续轨迹和字形轮廓构成，不使用人物、建筑、树木或风景插画，也没有数学课堂式标签。保留原120秒音乐时间轴；音效和视频导出由集成层处理。

工程根目录构建命令：

```powershell
.venv-reference/Scripts/python.exe -B -X utf8 tools/storybook/build_film.py
```

构建更新本目录 `generated/`、`resource_pack/shaders/glsl/story_showcase.fragment` 和 `resource_pack/textures/manim/story_showcase.png`。不修改数学片、播放器、场景注册、材质或音轨。最终统一构建与视频导出由工程集成入口完成。

开头第一行位于左上 `(-2,1.6)`，第二行位于右下 `(2,-1.2)`，宋体字号约 `.50`、最大宽度约 `9`。第一句1.0–4.6秒、第二句5.8–9.4秒逐字展开并淡入；每行下面有三束细长金色/青色曲线。第一句12–16秒收拢到 `(-.4,.2)` 的金色星核；第二句18秒变为位于 `(0,-2.72)` 的后续叙事字幕。托字的六条曲线始终保留各自身份，继续重构为轨道、风、旋涡和结尾的弧形框景。

主体时间轴如下：

| 时间 | 连续动作 |
| --- | --- |
| 18–34秒 | 风线弯成轨道，星核醒来；两层玫瑰曲线围绕同一核心旋转。 |
| 34–43秒 | 流星从左上沿弧线接近，金、青、紫三股尾迹沿运动方向渐细。 |
| 43–54秒 | 43.0秒击中核心，短促衍射光与扩张冲击环出现；原轮廓散成48段固定身份的碎片。 |
| 54–76秒 | 同一批碎片随连续风场漂流，六条风线卷成旋涡；颜色和身份保持稳定。 |
| 76–96秒 | 碎片按身份先后沿三次贝塞尔弧线归位。每片用8.4秒回收，首批84.4秒抵达，最后一片93.9秒完成；轮廓逐点重组为双层六瓣光核。 |
| 96–110秒 | 重组后的每段轮廓再次沿弧线展开，逐点变成四芒星，在中央留出文字空间。 |
| 110–120秒 | 110.2秒叙事字幕变成片名；113.5秒结语展开。原风线抵达上下两组弧形框景，星群停留。 |

48段碎片来自两条完整曲线的相邻参数区间。破碎、漂流、回收、再展开都使用同一编号和对应参数点，不在每帧重新随机生成。目标位置、颜色、回收顺序由固定编号决定；时间仅推进连续轨迹。后期四芒星也是这些曲线区间的对应点形变。12片碎片带回收尾迹，72颗彩色星尘提供纵深与运动细节。局部片段先做屏幕区域裁剪，每片最多16个线段；风线每条48段、流星尾迹每股28段，循环数量固定。辉光由局部解析衰减形成，不依赖额外后处理纹理。

后续字幕转换持续1.15秒，前句保留到下一次转换开始。共用 `tools/presentation/vector_morph.py` 对字形的外轮廓、组件和洞做匹配，再以等弧样本逐点变形；缺失组件从锚点展开或收拢。除用户指定的开场淡入外，不对整句做淡出后重新淡入。片名、结语也使用字形轮廓转换。端点使用原宋体SDF，中段是最多256记录的闭合多边形近似，不声称与Manim原生Transform逐像素相同。

渲染输入沿用现有约定：`EXTRA_VECTOR1=(时间秒,物理画布宽高比,物理画布像素高,不透明度)`，`EXTRA_VECTOR2=(翻转Y,顶部比例,高度比例,保留)`。`TEXTURE_0` 为原画面，`TEXTURE_2` 为4096图集。上半部存宋体SDF，下半部存源/目标轮廓的16位XY数据。字形采用Point/Clamp和手动双线性采样，点数据直接读取。16:9时坐标范围为x±8、y±4.5，实际内容限制在电影宽幅内。

字体来自工程缓存的固定Noto Serif SC官方源，400字重子集和SIL OFL1.1许可随生成目录保留。画面文案全部中文；若以后添加英文，必须沿用固定LaTeX字体流程。旧插画资产已经退出本版构建。没有新增素材或依赖。

本构建不启动游戏、不录制、不导出视频、不执行截图或人工验收。必要编译、原音乐合成和最终视频导出由集成层统一执行。
